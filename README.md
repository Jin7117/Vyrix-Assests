# Vyrix Assets

This repository contains UI asset exports for the Vyrix flow editing experience, including dark and light theme resources used in the interface.

## Included assets
- `vyrix/dark_theme/...` — dark mode screenshots and UI elements
- `vyrix/light_theme/...` — light mode screenshots and UI elements

These assets are intended for use in design review, implementation references, and frontend UI integration.

## Note
This repository is meant to store the visual asset pack for the Vyrix flow editing module and related interface states.
